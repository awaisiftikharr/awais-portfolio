# Awais Iftikhar — Developer Portfolio

Personal portfolio website for Awais Iftikhar, a Computer Science graduate focused on software engineering and full-stack development.

https://awaisiftikhardev.netlify.app/

## Tech stack

- React
- Vite
- Tailwind CSS
- JavaScript

## Run locally

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run build
```
